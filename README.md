# tiam-tiam eat

Placeholder link-tree site for the artist group **tiam-tiam eat**.

## Local development

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```

## Editing the placeholder

- English copy and links: `src/content/en.json`
- Traditional Chinese copy and links: `src/content/zh-Hant.json`
- Future images and media: `public/assets/`
- Layout and language switching: `src/App.tsx`
- Visual styling: `src/style.css`

The demo-work link intentionally points to `#` until a real destination is available.

## Deployment

Every push to `main` builds and deploys the static site through GitHub Pages Actions.

- Project Pages URL: `https://pillowlow.github.io/tiam-tiam-eat/`
- Custom domain: `https://tiam-tiam-eat.com/` (after DNS is configured)
